# 07. UI/UX

## 7.1 원칙

1. **비행 중 정보는 조종석 장치로** (P1). 비행 중 화면 오버레이로 허용하는 것은 ① IHADSS(헬멧 심볼 — 설정상 조종석 장치) ② 무전 자막 ③ 목표 알림 토스트 ④ 터치 조작 버튼뿐이다.
2. **메뉴 화면은 "작전실"** 톤: 어두운 남색 바탕(`#0b1320`, 현재 테마), 지도·서류·스텐실 글꼴 느낌의 강조, 노랑(`#ffd166`) 포인트. 현재 브리핑 카드 스타일을 확장한다.
3. **한 손가락, 두 번 탭 안에**: 타이틀에서 출격까지 최소 탭 수 — 즉시 출격 2탭, 캠페인 다음 임무 4탭(캠페인 → 임무 → 브리핑 "다음" → 로드아웃 "출격").
4. **모바일 가로 우선**, 터치 세로는 "가로로 돌려 주세요 — 전투는 가로 화면에서만 합니다" 안내(경기 중 화면만. 안내 동안 일시정지하고 코치를 숨긴다(#235). 배치 화면·메뉴는 세로도 동작, 데스크톱 좁은 창은 안내 없음).
5. 모든 비행 화면 텍스트는 최소 12px(CSS px), 터치 대상 최소 48×48px.

## 7.2 화면 흐름

```
[타이틀]
  ├─ 캠페인 ─→ [캠페인 지도] ─→ [브리핑] ─→ [로드아웃] ─→ [비행] ─→ [디브리핑] ─→ [캠페인 지도]
  ├─ 훈련 ───→ [훈련 목록] ──→ [브리핑(짧음)] ─────────────→ [비행] ─→ [결과] ─→ [훈련 목록]
  ├─ 즉시 출격 ─→ [즉시 출격 설정(위협 수준·시간대)] ───────→ [비행] ─→ [결과] ─→ [타이틀]
  └─ 설정 ───→ [설정]

[비행] 중 Esc / 일시정지 버튼 → [일시정지 메뉴: 계속 / 설정 / 조작법 / 임무 재시작 / 임무 종료]
[비행] 중 FARP 착륙 → [FARP 메뉴 (비행 화면 위 패널)]
```

화면 상태는 React 쪽 `ui/state.ts`의 단일 상태 기계로 관리한다: `{ screen: 'title' | 'campaign' | 'briefing' | 'loadout' | 'flight' | 'debrief' | 'training' | 'instant' | 'settings', missionId?, … }`. URL 해시(`#/campaign`, `#/flight/m03`)와 동기화해 새로고침해도 메뉴 위치를 유지한다(비행 중 새로고침이면 브리핑으로).

### 캠페인 지도

```

│   ▲ FARP                       │  위협: 대공포, 단거리 SAM    │

세로 화면이면 지도 위, 패널 아래로 쌓는다.

구현(M5-2, `src/ui/screens/Campaign.tsx`, `src/content/campaign.json`): 지도는 임무 지형이 아니라 전구(戰區) 전체를 나타내는 별도 지형(`campaign.json`의 `seed`)의 음영도다. 전선은 완료한 임무 수에 따라 `front` 키프레임(0·4·8·12개 완료) 사이를 보간해 북쪽으로 올라가고, 위쪽(VPA 점령지)은 붉게, 아래쪽(연합 통제)은 푸르게 칠한다. 노드는 완료(초록, 최고 평점 배지)·열림(노랑)·잠김(회색) 세 상태이고 누르면 오른쪽 패널이 바뀐다. 아직 만들지 않은 임무는 `campaign.json`의 요약·위협으로 패널을 채우고 `브리핑 ▶`을 막는다. 잠긴 임무의 브리핑·로드아웃 주소로 직접 들어오면 캠페인 지도로 돌려보낸다. 타이틀의 캠페인 버튼에 `N막 · 임무 완료수/12 · 계급`을 표시한다.

### 브리핑
- 왼쪽: 임무 지역 지도(지형 음영 + 웨이포인트 + BP + 알려진 위협 사거리 원 + FARP). 탭/클릭으로 확대.
- 오른쪽: 상황 설명, 목표 목록(주/보조 구분), 위협 목록, 기상·시간, 권장 무장.
- 하단: `[로드아웃 ▶]`.

### 로드아웃

```
┌──────────────────────────────────────────────────────────┐
│   (위에서 본 아파치 도면: 파일런 4개 + 날개 끝 + 기관포)      │
│    [L2 로켓19] [L1 헬파이어L×4]  ▲  [R1 헬파이어K×4] [R2 로켓19] │
│    날개끝: [스팅어 ×2 🔒]          기관포: [1200]            │
│                                                          │
│  연료  [━━━━━━━━──] 80%                                    │
│  총중량 7,210kg   호버 여유 ▓▓▓▓░░ 보통   예상 체공 18분      │
│                                                          │
│  [권장 무장 적용]                         [ 출격 ▶ ]        │

- 파일런을 탭하면 선택지(헬파이어 K / 헬파이어 L / 로켓 / 빈칸)가 순환한다. 잠긴 항목은 자물쇠 + 해금 조건 툴팁.
- **호버 여유**는 03장 무게 공식에서 계산: 호버 콜렉티브 < 0.65 좋음 / < 0.8 보통 / 그 이상 나쁨(빨강).

### 디브리핑
- 결과(성공/실패 + 사유), 평점 큰 글자, 점수 내역 표(02장 2.4절 항목별), 통계(비행 시간, 격파 수 유형별, 무장별 발사/명중, 받은 피해 계통별), 해금 알림. 버튼: `[다시 하기] [캠페인 지도]`.

구현(M4-6): `src/ui/mission/`의 `Briefing`(지형 음영 지도 360² + 도로·웨이포인트(BP는 파란 사각)·FARP·숨기지 않은 대공 유닛의 사거리 원, 상황·목표·위협·기상), `Loadout`(파일런 탭 순환 — 헬파이어 L은 해금 전 건너뜀, 날개 끝 스팅어는 잠금 표시, 기관포 300/600/1200, 연료 20~100% 슬라이더, 총중량·호버 여유·예상 체공 — 예상 체공은 캠페인 연소 배율 0.35 반영, #75), `Debrief`(성공/실패·사유, 목표 결과, 비행 시간·착륙 여부·피격 수·손상 계통, 유형별 격파, 무장별 발사·명중, 아군·민간 피해). 점수·평점은 M4-7. 캠페인 지도(M5-2) 전까지 타이틀의 `캠페인`은 임무 1 브리핑으로 간다. 흐름: 브리핑 → 로드아웃 → 비행(짧은 시작 카드: 목표 + `비행 시작` — 오디오 시작에 사용자 조작이 필요) → 디브리핑. 비행·디브리핑에서 새로고침하면 브리핑. 훈련 브리핑 카드는 그 훈련에 필요한 키만 보여 주고(`brief.keysFor`, #72) 전체 표는 일시정지 `조작법`에서 연다. 일시정지: 계속 / 조작법 / 설정(M7-1) / 음성 경고 / 다시 시작 / 임무 종료(주 목표가 다 됐고 착륙만 남았으면 성공, 아니면 실패 — 착륙 보너스 없음). 터치 세로 화면에서 비행 중이면 가로 안내를 덮는다. FARP 메뉴는 자막과 겹치지 않게 오른쪽 위.

### IHADSS 명세

현재 구현(`ihadss.ts`): 방위 테이프+목표 방위 캐럿, 속도, 레이더 고도+막대, 기압 고도, 승강 캐럿, 토크, 로터 저회전 경고, 수평선·피치 사다리(월드 투영), 호버 벡터, 목표 마름모. 여기에 다음을 추가한다.

| 요소 | 모양 | 위치 | 조건 |
| --- | --- | --- | --- |
| 비행 모드 표시 | `CRUISE` / `TRANS` / `HOVER` / `BOB-UP` 글자 | 좌하단 | 속도 > 60kt CRUISE, 10~60kt TRANS, < 10kt HOVER, 호버 중 키 `B` 누르면 BOB-UP |
| 가속 큐 | 호버 벡터 끝의 작은 원 | 호버 벡터 끝 | HOVER·TRANS에서만 |
| 호버 위치 상자 | 사각형(월드 고정) | 호버 모드 진입 지점 투영 | HOVER/BOB-UP에서. 기체가 그 위치에서 얼마나 떠내려갔는지 |
| 선택 무장 | `GUN 1180` / `RKT 38 ×2` / `MSL K 8 LOBL` | 우하단 | 항상 |
| 기관포 조준점 | 십자 + 원 | 머리 시선 중심 | 무장=기관포. 짐벌 한계 밖이면 `X` |
| 로켓 조향 커서 | I 모양 + 고각 막대 | 표적 방향 투영 | 무장=로켓 |
| 헬파이어 제약 상자 | 점선 사각형 (발사 가능 방위 ±20°) | 화면 중앙 | 무장=헬파이어. 표적이 상자 밖이면 기체를 돌려야 함 |
| 표적 표시 | TADS 시선: 작은 원 / 잠금: 원+십자 / FCR 표적: 삼각(방공)·사각(궤도)·원(바퀴) | 월드 투영 | 해당 센서 사용 중 |
| 위협 표시 | 화면 가장자리의 방향 호(arc) + 기호(`Z`=대공포, `S`=SAM, `M`=미사일) | 가장자리 | RWR/CMWS 경보 시 |
| 경고 문구 | `MISSILE` `ENGINE 1 OUT` `LAND NOW` 등 | 중앙 하단 | 03장 경고 목록, 깜박임 |

모든 IHADSS 요소는 **초록 한 색**(`#5dff6e`)과 모양으로만 구분한다(색 구분 없이 읽혀야 한다 — 색각 이상 대응이자 실제 IHADSS도 단색). 해상도 독립: 현재처럼 `u = min(w,h)/700` 배율.

### MPD 페이지

좌우 MPD는 현재 좌=FLT, 우=TSD 고정이다. 페이지 전환을 추가한다: 키 `[` / `]`(좌/우 MPD 다음 페이지), 또는 **조종석 안 MPD 베젤 버튼을 마우스로 클릭**(레이캐스트로 화면 좌표 → 베젤 버튼 판정, P1). 게임패드는 십자키 + 버튼 조합, 터치는 MPD를 탭하면 페이지 순환.

| 페이지 | 내용 | 기본 위치 |
| --- | --- | --- |
| `FLT` | 현재 구현 (수평선, 테이프, 호버 벡터, 토크, NR) | 좌 |
| `TSD` | 현재 구현 + 위협 사거리 원(알려진 위협, RWR로 확인된 위협), 웨이포인트·BP·FARP, 발견한 표적 기호, 윙맨 위치 | 우 |
| `WPN` | 기체 윗면 도면에 파일런별 남은 탄 수, 선택 무장, 미사일 모드(LOBL/LOAL, 레이저 코드), 대응책 잔량, ARM/SAFE | — |
| `TADS` | TADS 영상 축소판(5fps), 표적 정보(유형·거리·식별 상태) | — |
| `FCR` | 레이더 부채꼴, 표적 기호·우선순위 번호, 스캔 진행 | — (임무 6부터) |

구현(M5-3, `src/render/cockpit/pages/fcr.ts`): 지상 모드는 기체를 아래쪽 꼭짓점에 둔 ±45° 부채꼴(4·8km 호), 공중 모드는 원. 표적은 현재 기체 위치·기수 기준으로 스캔 시점 좌표를 찍는다. 기호는 삼각(방공)·사각(궤도)·원(바퀴)·마름모(헬기) + 우선순위 번호, 선택 표적은 호박색 모서리 괄호, 30초 지난 표적은 흐리게. 스캔 중엔 주사선이 움직이고 오른쪽 위에 `SCAN n%`, 끝나면 `TGT n`. 아래에 선택 표적 `번호 분류 거리`(움직이던 표적은 `MOV`). 잠겨 있으면 `FCR --`. IHADSS에는 30초 안 된 FCR 표적을 같은 기호·번호로 투영하고 선택 표적에 괄호를 친다(무장과 무관하게 표시).
| `ASE` | 생존 장비: RWR 원형 표시(위협 방향·종류·상태), 대응책 잔량·자동 모드 | — |
| `ENG` | 엔진 2개 토크·온도, NR, 연료 잔량·연소율·예상 체공, 계통 피해 상태(03장 표의 계통별 막대) | — |

구현(M2-7): 페이지는 `src/render/cockpit/pages/*.ts`, 페이지 상태·베젤 판정은 `cockpit/mpd.ts`. 지금 있는 페이지는 FLT·TSD·WPN·TADS·ASE이고 아래 베젤 B1–B5에 순서대로 붙는다(FCR은 M5-3에서 B6에 추가, ENG는 해당 작업에서). ASE는 10km 원형 위협 표시 + 플레어·채프 잔량 + AUTO/MAN. 베젤 버튼 클릭 = 그 페이지, 화면 부분 클릭·탭 = 다음 페이지, 키 `[` `]` = 좌/우 다음 페이지. 게임패드 전환은 남는 버튼이 없어 아직 없다. WPN의 레이저 코드는 고정 표기(`CODE A 1688`), 대응책은 M3-6 전까지 `--`, 마스터 암은 모델링하지 않아 살아 있으면 `ARM`. TADS 페이지 영상은 256² 후처리 영상을 0.2초마다 갱신(TADS 모드 중엔 끔, `renderer.mpdVideo`로 끌 수 있음 — 품질 설정이 생기면 low에서 끔). TADS 모드가 아닐 때 TADS 시선은 헬멧 시선을 따른다(슬레이브).

EUFD(가운데 주황 화면)는 현재처럼 경고 목록 + 연료·NR·TQ. 03장 경고 문구를 여기에 표시한다(가장 최근이 맨 위, 최대 6줄).

### 터치 (가로 화면)

```
┌──────────────────────────────────────────────────────────┐
│ [≡]                                              [TADS]  │
│                                                  [FCR ]  │
│                                                  [무장 ]  │
│                                                          │
│  ( 콜렉티브·페달 )   [대응책]        [레이저] [발사●]  ( 사이클릭 ) │
│      스틱                                           스틱   │
└──────────────────────────────────────────────────────────┘
```
- 현재 가상 스틱 2개 유지. 발사 버튼은 오른쪽 스틱 위쪽, 엄지를 스틱에서 떼지 않고 옆으로 밀어 누를 수 있는 위치.
- 스틱 영역 밖 한 손가락 드래그 = 머리 돌리기(현재 유지). TADS 모드에서는 = TADS 시선. 두 손가락 핀치 = 줌.
- `[≡]` = 일시정지. 시동·시점 버튼은 일시정지 메뉴 안으로 옮기고, 캠페인에서는 "시동 절차 생략"이 기본이라 시동 버튼 노출 불필요.
- 구현(M7-2): 왼쪽 위 `≡`(일시정지, 임무 표시는 그만큼 오른쪽으로), 오른쪽 위 2열 버튼 `TADS`(켜지면 강조) · `FCR`·`표적`(FCR 해금 시) · 현재 무장 이름(탭하면 순환) · `무전`(윙맨 지시 가능할 때), 왼쪽 스틱 옆 `플레어`·`채프`(채프 해금 시), 오른쪽 스틱 위 `발사`(64px)와 그 왼쪽 `레이저`(누르는 동안). TADS 모드면 가운데 아래에 줌 −/+·주간/열상. 시동 버튼은 엔진이 꺼졌거나 착지해 있을 때만 가운데 아래에 나오고, 일시정지 메뉴(터치)에 '외부 시점 전환'·'엔진 시동/정지'. 스틱 밖 두 손가락 핀치는 벌린 거리의 1.3배마다 TADS 줌 한 단계. 모든 터치 버튼 최소 48×48px.
- 구현(M7-2) 게임패드: RT 발사·LT 레이저, RB/LB는 TADS 모드면 줌 +/−, 아니면 무장 순환/FCR 표적 순환, A는 착지·엔진 꺼짐이면 시동, 비행 중이면 플레어, B 플레어·X 채프·Y 시점, 십자키 위 TADS·아래 FCR·좌/우 무장 이전/다음, Start 일시정지. 오른쪽 스틱을 누르고 있는 동안 오른쪽 스틱은 사이클릭 대신 머리(또는 TADS 시선)를 돌린다(초당 2.4rad × 감도).

녹음 파일은 `public/assets/audio/`(모노 MP3, 합계 약 350~520KB, 10장 10.3절). 재생·믹싱은 `src/audio/`. 구현(M7-4, `src/audio/mixer.ts`): 버스 4개 — 엔진(로터·터빈·바람·시동, 0.85), 무기(발사·폭발·피격, 1.0), 경고(비프·잠금음·RWR, 0.9), 무전(잡음, 0.9) → 마스터(설정의 전체 음량). 경고 비프·RWR 발사 단계·음성 경고(1.6초)·무전(0.8초) 동안 엔진 버스는 45%, 무기 버스는 60%로 덕킹(0.05초에 내려가고 0.6초에 돌아옴). 무전 버스는 320–3,200Hz 대역 필터 + 약한 tanh 왜곡으로 무전기 소리. 거리 감쇠는 역거리 모델 `ref/(ref + rolloff·(d−ref))`: 착탄음 기준 60m·2.5km 밖 무음, 폭발 기준 150m·롤오프 0.8·9km 밖 무음, 저역 통과는 거리에 따라 20kHz에서 400Hz까지. 경고음·RWR·스위치 소리는 합성 유지. 녹음 파일 로드 실패 시 합성음으로 폴백.

접근성 구현(M7-5): CSS 글자 12px 이상(테스트로 고정), IHADSS·TADS 글자는 작은 화면에서도 최소 12px, 터치 기기에서 모든 조작 대상 48px 이상, 무전 자막은 항상 켜짐, 상태를 색만으로 나타내지 않는다(위협·표적은 모양, 목표는 ✓/✗). 점검 목록은 #60.

회전 대응(#85): 문서 자체는 스크롤되지 않게 `html, body`를 화면에 고정하고(긴 메뉴는 `.menu` 안에서만 스크롤), 전체 화면 요소는 `100vh` 대신 `inset: 0`을 쓴다. 회전·창 크기 변경(`resize`·`orientationchange`·`visualViewport`)마다 스크롤을 원점으로 되돌리고 렌더러 크기를 즉시 + 300ms 뒤 한 번 더 맞춘다(모바일은 회전 직후 크기가 늦게 확정된다).

- 첫 실행: 타이틀에서 "처음이신가요? 훈련 1부터 시작하세요" 강조(훈련 1 미완료 시).
- 훈련은 **단계형 지시**: 화면 중앙 한 줄 지시("W를 눌러 콜렉티브를 60%까지") + 조건 달성 시 체크 → 다음. 현재 비행 화면의 `hint` 요소를 확장한다.
- 캠페인 임무에서 새 메커니즘이 처음 나오면 무전으로 1회 설명(예: 임무 4 첫 RWR 경보 시 "하운드 1, 레이더 경보다. 능선 뒤로 내려가라.").
- 구현(M5-7): 타이틀의 '처음이신가요?'는 훈련 1을 바로 여는 노란 버튼(느린 맥동, 동작 줄이기 설정이면 멈춤)이다. 단계형 지시는 임무 JSON `steps`(06장). 첫 등장 설명은 `coach` 이벤트 — 캠페인 임무에서만(훈련·즉시 출격 제외), 저장 데이터 `tips`에 없을 때 한 번: `rwr`(처음 레이더 추적), `missile`(처음 미사일 경보), `farp`(연료 35% 미만 또는 파일런 탄 소진), `fcr`(FCR 해금 후 첫 임무 시작), `airThreat`(적 공중 유닛이 처음 나를 발견), `night`(야간 임무 시작), `wingman`/`wingmanMenu`(윙맨 임무 시작, 지시 해금 전/후). 문장은 `strings.ko.json`의 `coach.*`이고 무전 자막 자리에 '관제: …'로 7초(임무 무전이 나오면 그쪽이 우선). 본 팁은 저장 데이터에 남아 다시 나오지 않는다.
