# 09. 로드맵

> 전장 모드 기준 1차 개정(B1-16, 2026-09-30). 작업의 원본은 위키 [10-로드맵](https://github.com/kyhsa93/karda/wiki/10-로드맵)이고, 작업마다 GitHub 이슈가 있다(마일스톤 B1~B10). 이슈 본문에 작업 내용·완료 조건·선행이 있다. 옛 M0~M7 로드맵(캠페인)은 이슈 #1~#61로 모두 완료·종료됐다.

## 9.1 원칙

- 마일스톤은 순서대로. 각 마일스톤 끝은 배포 가능한 상태(그때까지 만든 것만으로 한 판이 처음부터 끝까지 돈다).
- 작업 하나 = 커밋 하나. 끝나면 커밋에 `Closes #번호`, 이 문서의 체크박스를 `[x]`로.
- 모든 작업: `npm run check` + 회귀 기준([docs/battle/baseline.md](../battle/baseline.md)). 렌더·UI는 헤드리스 스크린샷, 수치는 하니스·벤치 결과표.
- 작업 중 발견한 문제는 그때그때 한국어 이슈로 등록한다.
- **사람 관문**(2026-10-03 결정 O5): 마일스톤마다 소유자가 기기에서 한 판 + 메모(녹화 또는 스크린샷 3장)를 남기기 전에는 다음 마일스톤을 시작하지 않는다. 첫 적용 #101.
- **P0 띠는 완료 조건**(O4): B3 병과·B4 이후 탈것은 그 역할의 영향력이 위키 01-비전 1.3의 P0 띠를 통과해야 끝난다.
- **역할 수치 동결**(O11): 역할 공정 비교 하니스(#193) 전에는 어느 역할의 수치도 조정하지 않는다.
